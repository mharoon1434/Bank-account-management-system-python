<h1 style="text-align:center; color:#0d6efd;">🏦 Bank Account Management System (Python CLI)</h1>

<p style="font-size:16px; line-height:1.7; color:#212529;">
A simple <b>command-line based Bank Account Management System</b> developed using
<b>Python</b>, demonstrating fundamental <b>Object-Oriented Programming (OOP)</b> concepts.
This system allows users to <b>create an account, login, deposit money, withdraw funds, and check balance</b>
through a clean and interactive interface.
</p>

<h2 style="color:#0d6efd;">🚀 Features</h2>
<ul style="font-size:15px;">
    <li>🔐 Secure Login System</li>
    <li>📝 Account Registration (Sign Up)</li>
    <li>💰 Deposit Money</li>
    <li>💸 Withdraw Money</li>
    <li>📊 Check Account Balance</li>
    <li>🔁 Menu-Based Continuous Navigation</li>
    <li>🧠 OOP-Based System Design</li>
</ul>

<h2 style="color:#0d6efd;">🛠️ Technologies Used</h2>
<ul>
    <li><b>Language:</b> Python 3</li>
    <li><b>Programming Paradigm:</b> Object-Oriented Programming (OOP)</li>
    <li><b>Interface:</b> Command Line Interface (CLI)</li>
</ul>

<h2 style="color:#0d6efd;">🧑‍💻 How It Works</h2>
<p>
The program starts with a <b>main menu</b> where users can log in or sign up.
After successful login, users can:
</p>
<ul>
    <li>Deposit money</li>
    <li>Withdraw money</li>
    <li>Check account balance</li>
</ul>
